# detonation-adiabat
Расчёт и визуализация детонационной адиабаты продуктов детонации твёрдых взрывчатых веществ.
Программа по плотности заряда и теплоте взрыва строит детонационную адиабату, прямую Михельсона и точку Чепмена–Жуге. Результат расчёта — оценка скорости детонации и давления Чепмена–Жуге и график этих кривых в плоскости «давление — удельный объём».

## Постановка
Рассматривается стационарная детонация твёрдого взрывчатого вещества. Плоский фронт движется по заряду с постоянной скоростью \(D\). Перед фронтом вещество покоится: давление \(p_0\), удельный объём \(v_0 = 1/\rho_0\). За фронтом реакция завершена, продуктам передана теплота взрыва \(Q\).
Состояния, достижимые одним таким скачком, образуют детонационную адиабату. Самоподдерживающаяся волна выделяет на ней одну точку — состояние Чепмена–Жуге. В этой точке прямая Михельсона касается адиабаты, скорость волны наименьшая среди стационарных режимов, а течение за фронтом звуковое:
\[
D = u + c.
\]
Здесь \(u\) — массовая скорость продуктов, \(c\) — скорость звука в них.
Скорость детонации и давление Чепмена–Жуге измеряют во взрывных опытах. Программа даёт их расчётную оценку.
При давлении в десятки гигапаскалей продукты детонации плотнее исходного твёрдого вещества, поэтому уравнение состояния идеального газа к ним неприменимо.
## Модель
На фронте выполняются законы сохранения массы, импульса и энергии.
Прямая Михельсона следует из сохранения массы и импульса:
\[
p - p_0 = \rho_0^2 D^2 (v_0 - v).
\]
Детонационная адиабата следует из сохранения энергии. Теплота взрыва \(Q > 0\) считается выделившейся:
\[
E - E_0 = \frac{1}{2}(p + p_0)(v_0 - v) + Q.
\]
Уравнение состояния продуктов — политропа
\[
E = \frac{pv}{n - 1}, \qquad n = 3.
\]
Начальное давление мало по сравнению с давлением за фронтом, \(p_0 \approx 0\). При этих условиях точка Чепмена–Жуге находится аналитически:
\[
v_{\text{ЧЖ}} = 0{,}75\, v_0, \qquad D = 4\sqrt{Q}, \qquad p_{\text{ЧЖ}} = \frac{\rho_0 D^2}{4}.
\]
Аналитическое решение используется для проверки программы.
